# ece.technion.ac.il — static demo copy

An unofficial static copy of https://ece.technion.ac.il/ (English + Hebrew) with
fixes and optimized media, for demonstration only. The live site is the
authoritative version; every page is marked `noindex` and its canonical link
points there.

- Open `index.html` (English) or `index-he.html` (Hebrew).
- Forms are disabled (they would submit to the live site); PDFs open directly.
- Site search in the header goes to the live site.

## Viewing

- **GitHub Pages:** push this folder as a repository, then Settings → Pages →
  "Deploy from a branch" → `main` / root. It works under `https://USER.github.io/REPO/`.
- **Locally:** `python3 -m http.server 8000`, then open http://localhost:8000/
